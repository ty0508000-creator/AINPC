# Mana Seed Character Base – free demo 2.0

Artwork by **Seliel the Shaper**.
Source: https://seliel-the-shaper.itch.io/character-base
Downloaded 2026-10-13: `FREE Mana Seed Character Base Demo 2.0.zip`.

Original Page 1 sheets are included for the game's village residents. Body, outfit, hair, and optional hat are layered through Unity SpriteRenderers; no source pixel edits. Original usage permission and demo limitations: `LicenseAndDemo.txt`. The author explicitly allows commercial and non-commercial use of this demo. Do not offer these source files as a standalone asset download.

Current village uses sixteen combinations of supplied farmer/forester clothes and colors, two hair styles, skin colors, and optional hats. Four standing directions use 64×64 cells at 24 pixels per unit. Standing is a single frame; walking/run frames exist in the source but residents do not move. Only Page 1 was imported; combat assets remain outside Assets.
