# Samurai 2D Pixel Art — 무료 버전

제작자: Mattz Art. 출처: https://xzany.itch.io/samurai-2d-pixel-art

사용자가 제공한 `FREE_Samurai 2D Pixel Art v1.2.zip`의 원본 파일을 보관한다.
백발·흰 수염의 노년 검객이며, 무료 버전에는 IDLE, RUN, ATTACK 1, HURT 스프라이트 시트가 포함된다.
이 폴더에 추가한 것만으로 기존 플레이어 프리팹이나 애니메이션 연결이 교체되지는 않는다.

이용 조건은 동봉된 `License.txt`를 따른다. 원본 라이선스와 Preview.png를 함께 보존한다.
