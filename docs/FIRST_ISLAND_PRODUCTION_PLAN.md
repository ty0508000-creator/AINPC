# 1섬 제작 기획서 — 재의 왕

작성 기준: 2026-09-21

이 문서는 신청서에 적힌 ‘기억 기반 상황 적응’ 목표를 실제 게임 한 장으로 보여주기 위한 제작 기준이다. 전체 사천왕과 천마 콘텐츠를 먼저 만드는 문서가 아니라, 이후 확장을 판단할 수 있는 수직 슬라이스 문서다.

## 1. 이번 제작에서 확정하는 기본안

신청서 원본은 현재 저장소에 없으므로, 기존 `논문_구현내용.md`와 2학기 계획을 기준으로 다음을 기본 결정으로 둔다.

- 정체성: 스토리 중심 무협 RPG + 기억 적응 연구.
- 섬의 핵심 선택: 주민 구조 여부.
- 시스템 선택: 위험할 때 내면에게 조작권을 맡길지.
- 보스의 기억 효과: 공격형 AI와 보호형 AI의 전투 방식 차이.
- 섬 종료: 보스 처치 후 다음 섬 예고.
- 사망 패널티: 성장·퀘스트·기억 유지, 체크포인트에서 재도전.

이 결정은 플레이어가 이해하기 쉽고 신청서의 연구 주장을 직접 보여주는 기본값이다. 신청서 원본에서 다른 필수 조건이 확인되면 이 문서의 결정표를 먼저 수정한다.

## 2. 1섬의 플레이 목표

플레이어는 폐허가 된 마을에서 생존자를 발견하고, 구조 여부를 선택한다. 전투 중 내면의 존재가 조작권을 가져가며, 이전 선택과 대화 기억에 따라 공격형 또는 보호형으로 행동한다. 플레이어는 재의 왕을 쓰러뜨리고 자신의 선택이 마을과 내면에 남긴 결과를 본다.

플레이어가 섬을 끝낸 뒤 이해해야 하는 문장은 다음이다.

> “내가 사람을 구하려 했던 기억 때문에 내면이 이번에는 공격을 늦추고 나를 보호했다.”

이 문장이 실제 플레이에서 성립하지 않으면 1섬은 완료된 것이 아니다.

## 3. 실제 퀘스트 흐름

### Q01. 잿빛 귀환

- 시작: 플레이어 생성 위치.
- 목표: 폐허 마을 입구 도달.
- 학습: 이동, 기본 공격, 수련 UI.
- 보상: 능력치 포인트가 아니라 다음 목표와 첫 체크포인트.
- 기억: `arrived_at_ruined_village`.
- 완료 조건: 마을 입구의 도달 이벤트. 단순 트리거는 허용한다.

### Q02. 살아남은 목소리

- 시작: 마을 입구 도달 후 자동 시작.
- 목표: 생존자 NPC와 실제 대화 완료.
- 학습: NPC 대화, 현재 사건과 과거의 차이.
- 기억: `heard_survivor_testimony`.
- 완료 조건: NPC 근처 진입이 아니라 대화 종료 이벤트.

### Q03. 이번에는 돌아간다

- 시작: Q02 완료.
- 목표: 습격받은 주민을 돕기로 선택하거나 외면하기.
- 선택지:
  - `rescue_villager`: 구조를 약속한다. Mood +8, 기억 중요도 1.0.
  - `leave_villager`: 위험을 피한다. Mood -5, 기억 중요도 0.8.
- 학습: 명시적 선택 UI.
- 완료 조건: 구역 진입이 아니라 버튼 선택 이벤트.
- 결과: 선택에 따라 다음 전투의 내면 반응과 생존자 대사가 달라진다.

### Q04. 첫 피

- 시작: Q03 선택 직후.
- 목표: 마을 주변 적 3마리 처치.
- 학습: 일반 공격, 대시, 무공 습득.
- 기억: `first_fight_after_return`.
- 완료 조건: 적 사망 이벤트 3회. 플레이어가 죽으면 Q04는 유지하고 체크포인트로 돌아간다.
- 보상: EXP와 첫 무공 포인트.

### Q05. 몸을 빌려라

- 시작: Q04 전투 중 Mood가 임계값에 도달하거나, 별도 연출 트리거 발동.
- 목표: 내면의 대화를 완료한다.
- 선택지:
  - `accept_control`: 짧은 시간 내면에게 조작권을 맡긴다. 공격형 프로필.
  - `keep_control`: 끝까지 직접 조작한다. 보호형 프로필이 아닌 ‘플레이어 유지’ 분기.
- 학습: 내면 대화, 조작권, Mood.
- 완료 조건: 대화 선택 이벤트.
- 주의: LLM은 대사와 추천 Mood만 만들고 선택·보상·조작권 적용은 게임 코드가 판정한다.

### Q06. 재의 왕의 문

- 시작: Q04 완료 및 Q05 완료.
- 목표: 보스 구역 도달, 보스전 준비.
- 기능: 체크포인트, 스킬트리, HP/MP 보충, 짧은 보스 설명.
- 완료 조건: 보스 문 앞 도달.

### Q07. 재의 왕

- 시작: Q06 완료.
- 목표: 보스 `AshKing` 처치.
- 보스 패턴 1: 근거리 휘두르기. 범위 표시 후 공격.
- 보스 패턴 2: 재 폭발. 안전지점 2개 중 하나를 선택해야 한다.
- 보스 패턴 3: 체력 50% 이하에서 추격 속도 증가.
- 내면 효과:
  - 공격형: 보스에게 접근하고 공격 빈도가 증가하지만 접촉 피해 위험이 커진다.
  - 보호형: 보스와 거리를 유지하고 위험한 재 폭발 때 후퇴한다.
- 완료 조건: `AshKing`의 실제 사망 이벤트. Choice 트리거로 완료하지 않는다.
- 보상: EXP, Q08 해금, 선택 결과별 생존자 반응.

### Q08. 첫 장의 끝

- 목표: 생존자에게 돌아가 결과 확인.
- 결과:
  - 구조 선택 + 보스 처치: 생존자 감사, 협력 기억 강화.
  - 외면 선택 + 보스 처치: 생존자는 살아 있지만 거리감 있는 반응.
  - 내면에게 맡김: 내면이 “이번에는 네가 돌아왔다”고 말한다.
- 완료 조건: 결과 대화 종료.
- 종료: “다음 섬에서 천마의 흔적이 발견되었다”는 예고 화면.
- 저장: 첫 섬 완료 상태와 선택 3개를 통합 저장.

## 4. 필요한 데이터

### 기억 ID

```text
arrived_at_ruined_village
heard_survivor_testimony
rescue_villager / leave_villager
first_fight_after_return
accept_control / keep_control
ash_king_defeated
isle1_completed
```

### 전투 프로필

첫 버전에는 두 개만 둔다.

| 프로필 | 이동 | 공격 | 위험 행동 | 선택 조건 |
|---|---:|---:|---|---|
| Aggressive | 빠름 | 공격 빈도 높음 | 접촉 위험 감수 | 내면 조작 수락 + 구조 기억 없음 |
| Protective | 보통 | 공격 빈도 보통 | 재 폭발에서 후퇴 | 구조 기억 있음 |

프로필 결정은 LLM 문자열을 직접 실행하지 않고 `Aggressive`/`Protective` Enum으로 제한한다.

## 5. 제작 순서와 완료 기준

### 0단계 — 문서 확정

완료 산출물: Q01~Q08 표, 기억 ID, 보스 조건, 선택지, 엔딩 문장.

완료 기준: 개발자가 퀘스트 ID와 완료 이벤트를 보고 구현할 수 있다. 빈칸이 있으면 Unity 작업을 시작하지 않는다.

### 1단계 — 회색상자 흐름

작업: 기존 맵에 임시 위치를 정하고 Q01~Q08을 트리거/임시 UI로 연결한다.

완료 기준: 새 저장으로 마을 → 선택 → 전투 → 보스 → 결과 대화를 중단 없이 한 번 완주한다. 그래픽은 임시여도 된다.

### 2단계 — 명시적 선택과 기억

작업: 선택 UI, 선택 결과 저장, 기억 조회, 퀘스트 분기.

완료 기준: 구조/외면을 각각 선택해 재실행했을 때 결과 대사와 Mood가 달라진다. 구역 진입만으로 Choice가 완료되지 않는다.

### 3단계 — 재의 왕 전투

작업: 보스 HP, 세 패턴, 실제 사망 이벤트, 보스 재도전, 체크포인트.

완료 기준: 보스 사망 이벤트가 한 번만 발생하고, 보스 사망 전에는 Q07이 완료되지 않는다. 두 AI 프로필의 전투 로그가 다르다.

### 4단계 — 기억→행동 실험

작업: Aggressive/Protective Enum과 AI 프로필을 연결하고 같은 전투를 두 조건에서 실행한다.

완료 기준: 맵·스탯·보스 HP를 고정했을 때 기억 조건만 바꿔 이동거리, 공격 횟수, 후퇴 횟수 중 하나 이상이 달라진다.

### 5단계 — 연출과 UI

작업: 목재 UI를 퀘스트/대화/선택/사망 화면에 확장하고, 기억된 선택을 플레이어에게 보여준다.

완료 기준: 플레이어가 목표, 선택 결과, 조작권 상태, 다음 목적지를 별도 설명 없이 알 수 있다.

### 6단계 — 사용자 테스트

작업: 3~5명에게 도움 없이 플레이시킨다.

기록할 것: 첫 선택 이해 여부, 다음 목적지, 조작권 변화 이해 여부, 보스 사망 원인, 같은 선택을 다시 하고 싶은지.

완료 기준: 막힘을 기능 추가로 덮지 않고, 막힌 위치와 원인을 수정한 뒤 재테스트한다.

## 7. 작업하지 않을 것

첫 섬 수직 슬라이스가 완주되기 전에는 아래 작업을 보류한다.

- 사천왕 2~4번째 섬 상세 퀘스트.
- 천마 최종전 구현.
- 스킬 개수 확장.
- 새 LLM 모델 학습.
- 모든 UI의 아트 교체.
- 대규모 MemoryManager 리팩터링.

이것들은 아이디어가 부족해서 미루는 것이 아니라, 신청서의 핵심 주장을 먼저 검증하기 위한 후순위다.

## 8. 의사결정표

| 결정 | 기본값 | 바꿀 수 있는 시점 |
|---|---|---|
| 게임 정체성 | 스토리+기억 적응 | 기획 확정 전 |
| 첫 선택 | 주민 구조 | Q03 구현 전 |
| 보스 AI | 공격형/보호형 2개 | 기억→행동 테스트 전 |
| 사망 | 진행 유지·체크포인트 | 사용자 테스트 후 |
| 섬 종료 | 다음 섬 예고 | 첫 섬 엔딩 구현 전 |

기본값을 바꾸지 않는다면 바로 0단계와 1단계를 시작하면 된다.
