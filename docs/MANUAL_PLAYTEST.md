# 첫 섬 데모 수동 검사 기록지

자동 검사로 확인하지 못한 Main 씬 입력·통합·플레이 경험을 검증하는 양식이다. 빈 체크박스는 통과가 아니라 미검증이다. 실제 사용자 저장을 삭제하지 말고 테스트 저장을 별도로 사용한다.

## A. 목재 UI

- [ ] Main에서 Play. 이전 HUD와 새 HUD가 겹치지 않는다.
- [ ] C로 능력치, K로 무공, Escape로 닫기. 선택한 탭이 명확하다.
- [ ] 네 강화 버튼을 마우스로 클릭한다. 점수 1 감소, 해당 수치 변화, 표시 갱신.
- [ ] 포인트 0에서 강화 불가. 잠긴 무공은 이유가 보인다.
- [ ] 학습 가능한 노드 선택 → 습득. 선행 무공/레벨/포인트 규칙이 유지된다.
- [ ] Q/R/F로 스킬이 동작한다. 하단 슬롯은 표시만 하며, 내력과 쿨타임을 연타로 우회할 수 없다.
- [ ] 기존 9개 무공 모두 최고 단계 달성 후 이기어검 수련 버튼으로 습득하고 저장·재시작에도 유지된다.
- [ ] Z로 검 5자루가 나타나 빠르게 반복 공격한다. 이동·일반 공격 중에도 유지된다.
- [ ] 궁극기가 8초 후 종료되고 내력 40·재사용 45초가 표시된다. 적 부재·처치·대화·사망·AI 전환에 검이 남지 않는다.
- [ ] 대화 입력창에서 C/K/Q/R/F/Z를 입력해도 성장/전투 입력으로 새지 않는다.
- [ ] 창을 열어도 적은 움직인다. 플레이어 입력 차단 정책이 설명과 일치한다.
- [ ] 1280×720 / 1920×1080에서 테두리, 글자, 버튼이 겹치지 않는다.
- [ ] 종료/재실행 후 투자/습득 상태 유지. 이전 저장은 먼저 백업한다.

## B. 실패에서 돌아오기 — 현재 미완성 항목 포함

- [ ] HP 0 → 사망 표시 → 재도전 → 조작 복구.
- [ ] 사망 상태로 종료/재실행 → 안전하게 복구.
- [ ] 내면 대화 중 정상 응답, 빈 응답, 지연, 예외, 닫기 → 시간/입력 복구.
- [ ] A 대화 지연 중 닫고 B 시작 → A의 뒤늦은 응답이 B를 바꾸지 않음.
- [ ] 모델/임베딩 누락 시 원인을 읽을 수 있고 대화 종료가 가능함.

## C. 첫 섬 진행 — 구현 후 통과시킬 항목

- [ ] 새 게임에서 순서대로 첫 섬 종료에 도달.
- [ ] 선택 구역에 들어가기만 해서는 선택/보스 조건이 완료되지 않음.
- [ ] 생존자 성공/실패 루트 각각에서 후속 진행 가능.
- [ ] 내면 요구 수락/거절 결과가 다르고 실제 보스 조건을 검사함.
- [ ] 보스 사망 이벤트 중복에도 보상이 한 번만 지급됨.
- [ ] 퀘스트 중 재실행해 목표/보상/플레이어 성장 상태가 일치함.
- [ ] 첫 장 종료를 명확히 보여 주며 없는 다음 섬을 안내하지 않음.

## 문제 하나당 남길 내용

1. 시작 상태: 저장/레벨/위치/열린 UI.
2. 누른 순서와 실제 발생 결과.
3. 기대한 결과.
4. 재현 횟수: 시도 몇 번 중 몇 번.
5. 화면 또는 로그 위치. 개인정보가 담긴 대화 원문은 공개하지 않는다.

# 마을과 네 사냥터 동선 추가 검사

## 스킬 키보드 조작 추가 검사

- [ ] WASD로 이동하며 Q 월영참, R 금강호신, F 운기조식, Z 이기어검을 사용한다. 먼저 무공을 습득하고 회복은 피해를 받은 상태에서 검사한다.
- [ ] HUD에 Q/R/F/Z가 표시되고 슬롯 클릭과 기존 1~4 키는 스킬을 시전하지 않는다.
- [ ] E NPC 대화 중이나 수련창·일시정지에서는 스킬이 시전되지 않는다.
- [ ] 사망 중 R은 재도전만 하고 내력이 줄거나 금강호신이 동시에 발동하지 않는다.

아래 항목은 사람이 직접 수행한 뒤 체크한다. 자동 검증 통과와 수동 플레이 완료를 구분한다.

- [ ] Main에서 현묵과 E로 대화한다. ESC로 닫으면 증언 목표가 남고, 확인하면 첫 사냥터 의뢰가 열린다.
- [ ] 첫 의뢰를 수락하고 북서쪽 입구를 밟는다. 요물 3마리를 잡고 마을에 돌아와 현묵에게 보고한다.
- [ ] 하연에게 두 번째 의뢰를 받아 북동쪽 강가의 서로 다른 파편 3개를 E로 조사하고 돌아와 보고한다.
- [ ] 세 번째 의뢰에서 남서쪽 피난처의 적을 잡고 소윤을 구한다. 적 처치 전에는 구조 선택이 열리지 않는다.
- [ ] 네 번째 의뢰에서 남동쪽 야영지의 적 5마리를 잡고 북쪽 문양을 조사한 뒤 현묵에게 보고한다.
- [ ] 각 지역 왕복 후 체력·내력·성장·부분 목표·조사한 파편·구조 선택이 유지된다.
- [ ] 사냥터에서 사망 후 R로 재도전하면 입구에서 살아나며 곧바로 마을로 튕기지 않는다.
- [ ] 기존 HUD·무공·이기어검과 새 대화 창이 함께 정상 표시되고, 대화 중 공격·이동이 멈춘다.
- [ ] 동굴 튜토리얼 작업 없이 마을 의뢰 흐름이 진행된다. 야영지 보고가 보스 처치로 기록되지 않는다.

## 재의 왕 추가 검사

- [ ] 야영지 보고 전에는 Main 남쪽 보스 문이 잠기고, 보고 후 전투터 입구로 이동한다.
- [ ] 제단에서 E로 정비를 확인하면 체력·내력이 회복된다. 취소하면 회복되지 않는다.
- [ ] 이전 보라색 삿갓 검객이 보스로 보이며, 전투 진입 시 체력바와 뒤쪽 봉쇄가 나타난다.
- [ ] 베기 예고 방향은 고정되고 뒤로 피할 수 있다. 폭발 예고 때 두 옥색 원에서 피해를 받지 않는다.
- [ ] 찌르기·십자·회전·검우·돌진·고리 폭발의 경고 모양과 화면 안내를 보고 각각 피한다. 검우는 이동 후 따라오지 않고 돌진은 벽을 통과하지 않는다.
- [ ] 레벨 4 검술 빌드로 처치 시간을 기록한다. 자동 검증 기준은 10분 13초이며 사람의 회피·적중률 차이를 별도로 기록한다.
- [ ] 반피 이하에서 잿불 표시와 빨라진 추격·공격을 확인한다.
- [ ] 사망 후 R로 입구에서 살아나고 보스 체력이 완전히 초기화된다. 벽으로 대시해도 무적이 계속 남지 않는다.
- [ ] 처치 후 문이 열리고 마을로 복귀한다. 현묵 보고를 확인해야 첫 장 완료가 기록된다.
- [ ] 재시작 후에도 처치·보고가 유지되고 보스가 재생성되지 않는다.

자동 씬 이동·재도전·저장 검사는 별도 슬롯에서 통과했다. 위 체크박스는 사람의 직접 플레이 기록으로만 표시한다.
