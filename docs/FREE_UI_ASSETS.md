# 현재 무협 RPG UI에 어울리는 무료 에셋 5개

확인일: 2026-09-20. 아래 다섯 항목 모두 Unity Asset Store 제품 페이지에서 FREE 표시를 확인했다. 아직 다운로드하거나 프로젝트에 적용하지 않았다. 가격·배포 조건은 나중에 바뀔 수 있다.

## 선정 방향

현재 [RpgUI.cs](../Assets/Script/UI/RpgUI.cs)는 색상만 지정한 Image 사각형을 조합하고, [RpgSkillEmblem.cs](../Assets/Script/UI/RpgSkillEmblem.cs)는 계열별 선 문양을 반복한다. 그래서 화면이 정돈되어 있어도 프레임 재질과 스킬별 시각적 개성이 부족하다. 이것이 템플릿처럼 느껴지는 한 원인이라는 디자인 판단이다.

아래 1~3은 전체 GUI의 대안, 4~5는 아이콘 보강 후보다. 다섯 개를 모두 섞기보다 GUI 한 종류와 아이콘 한 종류를 선택하는 것을 권한다. 무협 전용 패키지는 아니므로 서양 판타지 장식을 그대로 쓰는 것은 피하는 편이 좋다.

## 1. Bloodlines - Dark UI — 가장 추천하는 기반

- 제작자: Alebardium. 확인 버전 1.0.1, 최신 릴리스 2026-06-21.
- [Unity Asset Store 제품 페이지](https://assetstore.unity.com/packages/2d/gui/bloodlines-dark-ui-328721)
- 어울리는 용도: 성장 창 프레임, 탭, 버튼, HP/MP HUD를 하나의 어두운 판타지 스타일로 통일.
- 추천 이유: 천마·황폐한 마을·노쇠한 주인공이라는 분위기에 어두운 GUI가 잘 맞는다. 이는 프로젝트 설정을 바탕으로 한 추천 판단이다.
- 적용 방향: 먹색 바탕과 낡은 금색 테두리를 기본으로, 학습 가능 상태에는 옥색, 위험·봉인에는 탁한 붉은색을 제한적으로 사용한다. 고딕·흡혈귀 인상이 강한 장식은 줄인다.
- 주의: 스토어 호환성 표는 Unity 2022.3.62f2 기준이다. 현재 프로젝트의 Unity 6000.3.10f1에서 실제 검증한 것은 아니다.

## 2. Fantasy Wooden GUI : Free — 목재 느낌의 대안

- 제작자: Black Hammer. 확인 버전 2.1, 최신 릴리스 2019-02-18.
- [Unity Asset Store 제품 페이지](https://assetstore.unity.com/packages/2d/gui/fantasy-wooden-gui-free-103811)
- 어울리는 용도: 마을 상점, 의뢰 게시판, 수련 메뉴의 목재 프레임 계열.
- 추천 이유: 평평한 사각형 대신 재질감 있는 목재 방향을 선택하면 현재 UI와 인상이 달라질 수 있다.
- 적용 방향: 강한 갈색·노란색보다는 낮은 채도의 목재와 어두운 배경으로 조정한다. Bloodlines와 화면마다 무작정 혼합하기보다 별도 스타일 대안으로 본다.
- 주의: 원본 Unity 버전은 2018.1.3이다. 오래된 데모·스크립트보다 필요한 이미지 자산 위주로 검토하고 Unity 6 호환성을 확인해야 한다.

## 3. SIMPLE FANTASY GUI — 단순한 판타지 메뉴 대안

- 제작자: Nayrissa. 확인 버전 1.0, 최신 릴리스 2018-09-28.
- [Unity Asset Store 제품 페이지](https://assetstore.unity.com/packages/2d/gui/simple-fantasy-gui-99451)
- 어울리는 용도: 스탯 창과 스킬 상세 창을 판타지 GUI 방향으로 바꾸는 대안 후보.
- 추천 이유: 과한 공포·고딕 분위기 없이 메뉴의 게임다운 인상을 강화하고 싶을 때 비교해 볼 만하다.
- 적용 방향: 패널의 크기와 여백을 현재 게임에 맞추고, 한글 TextMeshPro 텍스트와 게임 로직은 유지한다.
- 주의: 원본 Unity 버전은 5.6.2로 오래됐다. 현재 uGUI에 이미지 소재를 활용하는 방향을 우선 검토한다. 패키지를 열어보지 않았으므로 특정 프리팹이나 9-slice 설정의 존재를 보장하지 않는다.

## 4. RPG icons free starter pack — 아이콘 보강 우선 후보

- 제작자: icreatepixels. 확인 버전 1.3, 최신 릴리스 2026-06-23.
- [Unity Asset Store 제품 페이지](https://assetstore.unity.com/packages/2d/gui/icons/rpg-icons-free-starter-pack-245521)
- 어울리는 용도: 무기·아이템 계열 아이콘, 향후 장비 슬롯과 보상 표시.
- 추천 이유: 스토어가 무기·아이템·코인 계열로 분류하고 있어 현재의 반복 선 문양을 보강할 후보로 적합하다.
- 적용 방향: 적절한 검 아이콘은 검술 계열에 활용할 수 있지만, 개별 무공 9개의 의미를 이 팩만으로 전부 표현할 수 있다고 가정하지 않는다.
- 호환성: 스토어는 현재 프로젝트와 같은 Unity 6000.3.10f1에서 Built-in/URP/HDRP 호환을 표시한다. 이는 제작자 표시이며 이 프로젝트에 가져와 검증한 결과는 아니다.
- 전체 UI 프레임을 제공하는 GUI 팩이 아니라 아이콘 팩이다.

## 5. FREE Medieval items Icons pack — 조건부 보조 후보

- 제작자: FlapjackMaker. 확인 버전 1.0.0, 최신 릴리스 2023-03-17.
- [Unity Asset Store 제품 페이지](https://assetstore.unity.com/packages/2d/gui/icons/free-medieval-items-icons-pack-245481)
- 어울리는 용도: 중세 무기·아이템 계열 아이콘을 이용한 장비·전리품 표시.
- 추천 이유: 무료 아이콘 대안으로 비교할 수 있다. 무협과 어울리는 소재만 선별하는 것이 전제다.
- 적용 방향: 4번과 동일한 슬롯에 섞어 넣기보다 둘 중 더 잘 맞는 그림체 하나를 선택한다. 무공 아이콘 전용 세트는 아니다.
- 중요 제한: 공식 호환성 표에서 Unity 2021.3.16f1 Built-in은 호환, URP/HDRP는 비호환이다. 따라서 우선순위는 낮다. 필요한 원본 이미지가 현재 UI에서 정상 표시되는지 별도로 확인해야 하며 그대로 작동한다고 보장할 수 없다.

## 권장 조합과 다음 적용 순서

첫 선택은 1번 Bloodlines를 GUI 기반으로 검토하고 4번 RPG icons를 필요한 슬롯에 보강하는 것이다. 밝고 생활감 있는 마을 중심 분위기를 더 원한다면 2번을 대안으로 고른다.

실제로 적용할 때에는 다음 순서가 적절하다. 아래 작업은 아직 수행하지 않았다.

1. 별도 테스트 장면에서 선택한 패키지의 이미지와 프리팹, 라이선스 문서를 확인한다.
2. RpgUI의 Box 생성부에 프레임 Sprite를 연결한다. 늘어나는 패널은 해당 이미지에 적절한 테두리 정보가 있을 때 9-slice를 설정한다.
3. 스킬 아이콘을 데이터로 연결하고, 잠김·학습 가능·선택·최대 랭크를 밝기뿐 아니라 테두리와 기호로 구별한다.
4. 기존 PlayerStats, LearnSkill, TryCast, 저장 형식은 유지한다.
5. 한글 글리프, 다양한 화면 비율, 버튼 클릭 영역, 쿨다운 표시와 플레이 중 입력 차단을 다시 검증한다.

## 조사 한계

제품 페이지의 FREE 표시와 버전·호환성 정보를 확인한 추천이다. 실제 패키지 내용물을 가져와 개별 파일까지 검수한 목록은 아니다. 페이지에 AI 제작 표시가 있는 후보는 최종 목록에서 제외했지만, 표시가 없다는 사실만으로 모든 후보의 제작 과정이 비생성형 AI라고 인증할 수는 없다. 사용자 요구의 핵심인 획일적인 외형 개선과 제작 도구의 출처는 구분해서 판단해야 한다.
